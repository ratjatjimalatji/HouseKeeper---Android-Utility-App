# HouseKeeper

Before starting any new feature or screen work:

1. Read `memory.md`: design decisions, gas model facts, and repo and Git conventions (for example, `gh` must use `--repo ratjatjimalatji/HouseKeeper---Android-Utility-App`).
2. Read `progress.md`: find the feature's row, its prototype key and its Compose target, and check it isn't blocked.
3. Build to match `design/design-system.html` and `design/prototype.html#<key>`, using the tokens in `design/hk.css`.
4. In the same PR, update `progress.md` (status + PR number), and update `memory.md` if a decision changed.

Use the GitFlow workflow (`/gitflow`) for all changes.
