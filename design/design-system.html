HouseKeeper Design System

Foundations and components for the HouseKeeper Android app. Every component is shown in each state it can be in: default, pressed, focused, disabled, loading, error and empty. The tokens live in hk.css, which the interactive prototype also uses, so this page and the prototype always match. Click any hex value to copy it.

Colour HkColors

Amber is used as a fill, with dark ink on top: buttons, the Scan button, selected states. Amber text on white fails contrast, so text and icons use Amber Text #8F5600. Each utility has its own colour, and status colours are kept separate from utility colours.

Typography HkType

Two families. Roboto for all words. Roboto Mono for anything you read off a meter: readings, units, money, countdowns, plus small uppercase labels. Monospaced digits line up in lists and don't jump while a scan updates.

Aa
Roboto

Weights 400 Regular, 500 Medium. Used for headings, body, buttons and navigation. The Android system default, so no extra download on most devices.

0.9
Roboto Mono

Weights 400, 500. Used for meter readings, kWh/m³/kg values, rand amounts, run-out countdowns, join codes and LABELS.

Spacing, shape, elevation

A 4 pt grid. Screen side padding is 16. Cards sit 8–12 apart. Use borders before shadows: shadows are only for things floating above the page (the Scan button, sheets, dialogs, snackbars).

Motion

Standard: 180 ms, cubic-bezier(.2,0,0,1) (Material emphasized). Snackbars stay 6 s when they offer Undo, 4 s otherwise. Skeletons shimmer at 1.2 s. Respect the system's "Remove animations" setting.

Icons

Material Symbols Rounded, 24 dp grid, drawn at 22 / 18 / 15. Outlined by default; filled for the active nav tab and the utility icons. Never emoji.

Buttons HkButton

One primary action per screen area. Labels say what happens ("Save reading", "Buy electricity"), never "OK" or "Submit". 44 dp tall by default (48 dp touch target with spacing), 36 dp small, 52 dp large for the main action in a sheet.

Sizes

  • Loading keeps the button's width, swaps the icon for a spinner and changes the label to the action in progress ("Saving…"). The button can't be tapped while loading.
  • Disabled is only for actions that will become possible on this screen (for example Save before a reading exists). Otherwise hide the action, or explain why it's blocked.
  • Danger is only for actions that can't be undone, and it always opens a confirmation dialog first.

Icon buttons & Scan button

Icon buttons are 40 dp with a 1 dp border. The Scan button is the app's main action. It sits raised in the centre of the nav bar on every tab, and is the only element besides primary buttons that uses an amber fill.

Gas cylinder GasCylinder · PropaneGasCylinderComposable

A restyle of the existing tracker. The drawing keeps the Canvas proportions from PropaneGasCylinderComposable.kt: height follows the size (4 kg 190, 9 kg 225, 14 kg 265, 48 kg 305). Its colour is the user's real cylinder colour from DefaultGasCylinderColors. A dashed line and faded top show the projected gas left. The same drawing is reused small in list rows, so a cylinder is always shown in its own colour and proportions, never as a generic icon.

Sizes · dynamic height

Projected level

  • Level = (size − kg/day × days in use) ÷ size. The kg/day rate is the average of finished cylinders (size ÷ days lasted). With none, use the size's default from CylinderSizeInfoList.
  • Days-left colour: under 5 days Danger, under 10 Electricity amber, otherwise Success.
  • New cylinder is the greyed, dashed placeholder on page 1 of the carousel, exactly as today.

Empty states HkEmpty

Every empty state has three parts: what's missing, why it matters to this household, and one action that fixes it. Never a dead end, never a made-up number.
